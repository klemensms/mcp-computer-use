# v0.1.0-beta.1 — Initial release

First public beta of `@mcp-consultant-tools/computer-use`.

## Features

- 9 MCP tools: `screenshot`, `click`, `type_text`, `key_press`, `scroll`, `wait`, `list_windows`, `get_frontmost_window`, `check_permissions`
- Default-secure safety model:
  - Per-app bundleId allowlist (default: Obsidian, Finder, System Settings, Ghostty, cmux, Figma Desktop, Calculator)
  - 250ms rate limit on write actions
  - `type_text` secret scan (`sk-`, `ghp_`, `AKIA`, `xoxb-`, long base64)
  - JSONL audit log at `~/.local/state/mcp-computer-use/audit.log` with redacted params
- PROFILE presets: `stealth` (default), `permissive`, `readonly`, `confirm`
- `READONLY=1` hides write tools entirely (registration-time filter, not just a gate)
- Full CLI parity via `mcp-cu-cli`
- Swift helper compiled from source on install — no prebuilt binaries shipped

## Derivation

Swift helper seeded from [injaneity/pi-computer-use](https://github.com/injaneity/pi-computer-use) commit `96434a7` (MIT © Zane Chee) and extended here (`keyPress`, `scroll`, `shutdown`, `listWindows(bundleId:)`). This project owns the helper going forward; no upstream wire-compat commitment. See `NOTICE` + spec §8 revision 2026-04-22b.

## Install

```json
{
  "mcpServers": {
    "computer-use": {
      "command": "npx",
      "args": ["-y", "--package=@mcp-consultant-tools/computer-use@beta", "mcp-cu"]
    }
  }
}
```

Requires macOS 14+ and Xcode Command Line Tools.

## Known limits (v1)

- `listWindows` pid attribution is heuristic for multi-instance apps
- Sensitive-app redaction is a stub (v1.1)
- No drag / double-click / right-click in v1

## Upgrade path

None (initial release). Future versions bump `0.1.0-beta.N`.
